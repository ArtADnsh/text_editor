# Simple Text Editor (Undo / Redo) – C++

This project is a **command-line text editor** implemented in **C++** as a mini project for **Data Structures & Algorithms (DSA)**.

The main goal of this project is to demonstrate the practical use of **Stack** data structure by implementing **Undo** and **Redo** functionality.

---

## ✨ Features
- Insert text at a specific position
- Delete text from a specific position
- Copy & Paste functionality
- Undo last operation
- Redo undone operation
- Print current text state

---

## 🧠 Data Structures Used
- `stack` (for Undo and Redo operations)
- `string`
- `struct` (to store action details)
